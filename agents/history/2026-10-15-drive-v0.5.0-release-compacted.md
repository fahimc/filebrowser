## Verification

- Production frontend builds and both Go executable builds passed. Version
  readback confirms the tag and main EXE source commit.
- Focused Go officecollab/officehistory tests passed.
- Isolated main EXE with no external web assets passed the full Office smoke:
  DOCX/XLSX/PPTX edits persist, PDF annotations, four-format creation,
  failed-save recovery/close-before-autosave, editable/view-only shares.
- Real browser native upload through a deliberately delayed loopback proxy
  showed Saving/server confirmation and disabled Pause until acknowledgement;
  file bytes matched after success. Playwright route interception itself holds
  XHR upload events, so the acknowledgement test uses an actual HTTP proxy.
- Photos duplicate saved a numbered copy and preserved original bytes. A 6 MiB
  Photos upload with an injected HTML 502 on chunk two resumed at the confirmed
  5 MiB offset and matched all final bytes; error text remained readable.
- Embedded Studio opened an image and saved back to the original through its
  FileBrowser adapter. Separate Photos.exe loaded the same library and image.
- Portable ZIP CRC passed; executable hashes inside it match raw assets.
  Package excludes runtime databases, private config and logs. Combined source
  ZIP includes FileBrowser, ranuts editor/patches and Studio source.
- Tests used synthetic loopback noauth data. No clean-host, public MyAccounts/
  Cloudflare, Android or full backend-suite acceptance is inferred. CGO-free
  build omits MuPDF thumbnails. Editor bundle size warnings remain.
